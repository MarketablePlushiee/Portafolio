Professional web portfolio repository designed with a lightweight CRT retro-terminal aesthetic. Built to showcase projects in **Applied Artificial Intelligence**, **Extended Reality (XR)**, and **Digital Game Engineering**.

### 🛠️ Architecture & Core Features

* **Interactive Hero Terminal:** Executes live system commands (`hello world`, `help`, `credits`, `clear`, `lang es/en`) with typewriter animation and real-time command processing.
* **Web Audio API Synthesizer:** Procedural sound generation (*keyclicks*, *boot sounds*, *hover effects*) and ambient drone audio using native oscillators and gain nodes without heavy audio files.
* **Bilingual Engine (EN / ES):** Data-attribute language switching (`data-lang`) with `localStorage` persistence.
* **Lightbox & Embedded Demos:** Interactive image viewer for machine learning metrics (TensorBoard, confusion matrices) and iframe integration for WebGL playable demos and YouTube videos.
* **Framework-Free Performance:** Pure HTML5, CSS3 (Variables, Grid, Flexbox), and ES6+ JavaScript for fast load times and seamless GitHub Pages hosting.

### 🛠️ Arquitectura Web y Características Principales

* **Consola Terminal Interactiva en Hero Section:** Permite ejecución de comandos personalizados (`hello world`, `help`, `credits`, `clear`, `lang es/en`) con efecto de máquina de escribir e interprete en tiempo real.
* **Sintetizador Web Audio API:** Generación procedural de efectos de sonido (*keyclick*, *boot*, *hover*) y ruido ambiental (*drone*) mediante osciladores nativos sin depender de archivos pesados.
* **Motor Bilingüe Nativo (EN / ES):** Sistema de traducción por atributos de datos (`data-lang`) con persistencia en `localStorage`.
* **Lightbox e Integración de Demos:** Visor interactivo para métricas de modelos (TensorBoard, matrices de confusión) e incrustación de reproductor de demos en WebGL y vídeos demostrativos.
* **Cero Frameworks Pesados:** Desarrollado completamente en HTML5, CSS3 nativo y JavaScript ES6+, garantizando tiempos de carga casi instantáneos en GitHub Pages.
